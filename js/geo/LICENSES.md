# Geo data

- **land-dots.js**: derived from Natural Earth 1:110m land via world-atlas (public domain).
- **places.js** city names and coordinates: GeoNames (https://www.geonames.org), licensed CC BY 4.0, via the all-the-cities package.
- **places.js** airport codes and coordinates: OpenFlights (https://openflights.org/data), licensed under the Open Database License (ODbL) 1.0. This file is a derived database and is available under the same licence.

Regenerate with `node tools/make-geo.mjs`.
